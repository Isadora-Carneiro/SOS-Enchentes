SOS Enchentes

Sistema desenvolvido como solução para organização e registro de pedidos de ajuda em cenários de enchentes. O projeto permite que pessoas afetadas registrem solicitações de apoio, facilitando a visualização e gestão dessas informações.

1. Apresentação da Ideia

Este projeto surgiu a partir do desafio sobre enchentes e a necessidade de melhorar a comunicação e organização de pedidos de ajuda em situações de emergência.

Em cenários de enchentes, muitas pessoas ficam sem acesso rápido a apoio ou informação. Pensando nisso, foi desenvolvido um sistema para registrar e listar solicitações de ajuda, centralizando essas informações em um único lugar.

2. Problema Escolhido

O problema escolhido foi a dificuldade de organização e centralização de pedidos de ajuda durante enchentes.

Em situações reais, informações acabam se perdendo em redes sociais ou mensagens dispersas, o que dificulta o atendimento rápido às pessoas afetadas.

3. Solução Proposta

A solução proposta é um sistema web que permite:

Cadastro de pedidos de ajuda (nome, cidade e descrição)
Listagem dessas solicitações
Armazenamento das informações em banco de dados

O sistema centraliza os dados para facilitar a visualização e organização das necessidades.

4. Estrutura do Sistema

O projeto foi dividido em três partes principais:

Front-end

Responsável pela interface do usuário, permitindo o envio e visualização dos pedidos de ajuda.

Back-end

Desenvolvido com Node.js e Express, responsável pela criação da API e regras de negócio.

Banco de Dados

Utiliza PostgreSQL para armazenamento estruturado das informações.
